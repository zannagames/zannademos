CAT 'N' MOUSE 1.1.7
The Midnight Cheese Heist

Requires an Apple silicon Mac (M1 or later), macOS 14 Sonoma or later.
This package is not an Intel/universal build.

INSTALL
1. Unzip the download and double-click the .dmg file.
2. Drag Cat 'n' Mouse into the Applications folder shown in the disk image.
3. Eject the disk image. Open Cat 'n' Mouse from Applications.

FIRST LAUNCH / GATEKEEPER
This build uses ad-hoc signing with the hardened runtime, like the Legacy
Baseball demo. Its bundle signature is checked for integrity, but it is NOT
Developer ID signed or notarized by Apple. macOS may block the first launch
after download.

Only if you trust the source of this copy:
1. Try opening the installed app once, then dismiss the warning.
2. Open Apple menu > System Settings > Privacy & Security.
3. Find the notice for Cat 'n' Mouse and click Open Anyway.
4. Authenticate and confirm Open when macOS asks.

This creates an exception for this app; it does not disable Gatekeeper for
other software. Managed Macs may prohibit exceptions. Do not bypass an
explicit malware warning or an invalid/damaged signature: obtain a fresh
copy and check its checksum instead.

Apple's instructions:
https://support.apple.com/102445

PLAY
Collect all twelve cheese pieces, then find the exit that appears, in each
of ten rooms. Every room also requires boxing in every roaming cat first.
Cats roam in real time and drop crates behind them; crates block their
deadly straight sightlines. Amber sentries only hunt while they glow. Push
crates by walking into them. Grab the star bonus before it hops away. If a
cat spots you it walks over before you lose a life. Backspace restarts a
room for one life when the cheese gets boxed in.

Move: arrow keys / WASD / controller D-pad or left stick (hold to run)
Wait: Space / controller X (Square)
Restart room: Backspace or T / controller left bumper
Confirm: Enter / controller A (Cross)
Back: Escape / controller B (Circle)
Pause: P / controller Start (Options)
Help: H or F1 / controller Back (View)

Settings offers Cozy, Classic and Fierce difficulty, separate music and
sound-effect toggles, danger-lane display and reduced motion. High scores
are local and separated by difficulty. Difficulty changes affect new runs.

Settings and scores are stored outside the app in:
~/Library/Application Support/Zanna/catnmouse/
Uninstall by moving only the app to Trash. This preserves your scores.

VERIFY
The accompanying .dmg.sha256 file verifies the disk image:
  shasum -a 256 -c Cat-n-Mouse-1.1.7-macos-arm64.dmg.sha256
An integrity checksum is not proof of the publisher's identity. This build
does not claim automatic Gatekeeper approval or Apple notarization.
