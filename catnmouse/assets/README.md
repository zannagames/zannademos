# Character skins and optional overrides

The four character portraits below ship in this directory. Every other sprite is
generated by `art.zia`, which also stands in for any of these files if it is
removed. Add or replace any of these PNG files here and restart to change a
sprite; the game code does not change:

| File | Role |
| --- | --- |
| `floor.png` | Floor tile |
| `wall.png` | Fixed masonry |
| `crate.png` | Pushable wooden block |
| `cheese.png` | Pickup |
| `mouse.png` | Player — **ships here** |
| `cat_sentry.png` | Black stationary cat — **ships here** |
| `cat_stalker.png` | Tan wandering cat — **ships here** |
| `cat_prowler.png` | Violet wandering cat, faster — **ships here** |
| `exit_closed.png` | Locked arch (house-map icon) |
| `exit_open.png` | Open arch, drawn once the exit appears |
| `bonus.png` | Star bonus pickup |
| `crate_new.png` | Pale crate dropped by a wandering cat |

`cat_prowler.png` is derived from `cat_stalker.png` by `../tools/make_skins.zia`,
which rotates fur hue to violet while keeping each pixel's lightness, alpha and
blue eyes. Run it from the project directory (`zanna run tools/make_skins.zia`)
after changing the stalker so the two roamers stay one cat in two colours.

Use 64 by 64 RGBA PNGs; other sizes are scaled to 64 by 64 with nearest-neighbor
sampling. Keep characters inside the tile and use transparent backgrounds.
Floor and wall artwork should fill their tile. Alpha is composed by the native
RenderTarget2D, including partially transparent edges. UI text, lane bands,
sentry glow, the catch halo and the house-map diagram remain procedural so they
always match the live rules.

Search order: `CATNMOUSE_ASSETS` (when set, this is the only directory), `assets`
beside the executable, `../Resources/assets` beside a macOS bundled executable,
`assets` in the working directory, `zannademos/catnmouse/assets`, then
`catnmouse/assets`. Missing files use generated artwork; unreadable files print
`Ignoring unreadable PNG: <path>` and also fall back. The manifest includes this
directory when packaging. Ordinary `zanna build` creates the executable; copy
this directory beside it if you want custom artwork outside the source tree.
